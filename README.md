# ICT Asset Management: Frontend

Next.js 14 + TypeScript + Tailwind CSS. Talks to the backend only through REST.

## Run
```
cp .env.example .env.local           # NEXT_PUBLIC_API_URL=http://localhost:5000/api
npm install
npm run dev                          # http://localhost:3000
```
Start the backend first (see its README) and sign in with the seeded admin account `admin@ict.local` / `Admin@12345` (development only).
